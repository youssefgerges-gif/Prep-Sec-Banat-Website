# Marmina-Church-Sunday-School-Banat-Prep-Secondary

نظام خدمة مدارس الأحد — إعدادي وثانوي بنات (كنيسة مارمينا والبابا كيرلس).

## النظام
- 6 فصول: أولى / تانية / تالتة إعدادي، وأولى / تانية / تالتة ثانوي (القائمة في `CLASSES` جوه `src/services/supabase.js`).
- دوران بس: **خادم** و**مخدومة**. كل الخدام صلاحياتهم واحدة وبيشوفوا كل الفصول.
- الحضور والافتقاد للمخدومات بس (مفيش غياب للخدام ولا اجتماع خدام).
- مدارس الأحد الخميس 6:00 م: تسجيل الحضور يوم الخميس بس. النقاط الأساسية 2، واللي تيجي لحد 6:05 م (حتى لو بدري) تاخد 5 كمكافأة (بتوقيت القاهرة). زيادة/خصم النقاط اليدوي موجود في شاشة "إضافة نقاط".
- شاشات الخادم: الإحصائيات، لوحة الصدارة، تسجيل الحضور (QR أو يدوي)، إضافة نقاط، الافتقاد، أعياد الميلاد، إضافة مخدومة، أكواد QR، الكشوفات.
- الفقرة الافتتاحية: درجات الفصل ككل (ترنيمة / قراءة إنجيل / أسئلة / هدوء + عدد الخدام × 5) مع صدارة اليوم والصدارة العامة.
- بياناتي: كل حساب يعدّل تليفونه وتاريخ ميلاده بنفسه. حساب التدريب (is_training_account) يقدر يبدّل بين خادم ومخدومة.
- بيانات المخدومة (تاريخ الميلاد / العنوان / رقم ولي الأمر) اختيارية وقت الإضافة، وعليها علامة "بيانات ناقصة" لحد ما تتكمل من شاشة "أكواد QR".
- التسجيل اليدوي للحضور: لمسة تسجل ولمسة تلغي، وينفع تسجيل حضور لخميس فات.
- أعياد الميلاد: قايمة مخدومات كل شهر (من تاريخ الميلاد) وزرار "تم الاستلام" لهدية الحفلة (آخر خميس في الشهر). تنبيه جوه الموقع بعدد أعياد الميلاد، وإشعارات موبايل اختيارية (شوف `NOTIFICATIONS-SETUP.md`).

## التشغيل
1. `npm install` ثم `npm run dev`.
2. من غير ملف `.env` بيشتغل في **وضع تجربة محلي** (الداتا في المتصفح بس). ادخل بالكود `SRV01` واختار كلمة سر.
3. للتشغيل الحقيقي: اعمل مشروع Supabase جديد، شغّل `schema.sql` كله في SQL Editor، وحط بيانات المشروع في `.env` (شوف `.env.example`).
   - `schema.sql` بيعمل أول حساب خادم بالكود `SRV01` لو مفيش أي خادم. ادخل بيه، غيّر اسمه، وضيف باقي الخدام من شاشة "الكشوفات".
   - من إعدادات Supabase Auth: اقفل "Confirm email".
